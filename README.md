# Gravimãe Fotografia 📸🤰

> Website e portfólio oficial da **Gravimãe Fotografia** — Ensaios afetivos de gestante, parto, recém-nascido (*newborn*) e família por **Bruna**.

---

## 🎨 Sobre o Projeto

Landing page elegante, acolhedora e responsiva, desenvolvida especialmente para o nicho de fotografia materno-infantil. O design reflete sensibilidade e aconchego através de uma paleta em tons de terracota, areia e café, valorizando os laços familiares e a poesia da espera.

### 🌟 Destaques
- **Identidade Visual Autoral:** Tipografia clássica serifada combinada com a paleta terracota extraída do estúdio da fotógrafa.
- **Portfólio & Ensaios:** Seções dedicadas para *Ensaio Gestante*, *Parto & Nascimento* e *Newborn & Família*.
- **Alta Performance:** HTML5 semântico, CSS moderno e Vanilla JavaScript (zero dependências pesadas).
- **Conversão Otimizada (CRO):** Botão flutuante e botões de chamada rápida para agendamento direto via WhatsApp.
- **Acessibilidade & SEO:** Metatags Open Graph completas, favicon personalizado, suporte a `prefers-reduced-motion` e link de salto (`skip link`).

---

## 🚀 Tecnologias

- **HTML5** (Semântico & Acessível)
- **CSS3** (CSS Grid, Flexbox, Variáveis Customizadas e Animações Fluidas)
- **JavaScript Vanilla** (`IntersectionObserver`, ScrollSpy e Menu Mobile)
- **Google Fonts** (*Cormorant Garamond* & *Inter*)

## 💻 Como Executar Localmente

1. Clone o repositório:
   ```bash
   git clone https://github.com/phfirminodev/gravimae-fotografia.git
   ```
2. Acesse a pasta:
   ```bash
   cd gravimae-fotografia
   ```
3. Abra o `index.html` diretamente no seu navegador ou utilize um servidor local:
   ```bash
   python -m http.server 8000
   ```
4. Acesse em `http://localhost:8000`.
